# Contributing Guide

Thank you for contributing to this project.

## Branch Naming
- Use descriptive names with lowercase words separated by hyphens.
- Prefix feature branches with `feature-`, bug fixes with `fix-`, and maintenance work with `chore-`.
- Example: `feature-add-contributing-guide`.

## Commit Message Conventions
- Use the format `type: short description`.
- Common types: `feat`, `fix`, `docs`, `refactor`, `test`, and `chore`.
- Keep the subject concise and use the imperative mood.
- Example: `docs: add contributing guide`.
